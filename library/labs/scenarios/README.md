# 시나리오 규격과 상품별 매트릭스

각 시나리오는 하나의 JSON 레코드이며, 아래 필드를 갖는다. 실제 파일은 `rounds/<R>/scenarios.json`
(R01 규격은 `kind` 필드로 `credit` / `transfer` / `loan_limit`을 구분한다).

| 필드 | 설명 |
|------|------|
| `id` | 시나리오 ID (상품 접두어 + 번호, 예: `loan-0001`) |
| `product` | `deposit` `savings` `loan` `insurance` `securities` `wallet` 중 하나 |
| `inputs` | 재무제표 입력(bs/pl/cf), 금액, 만기, 연체 여부 등 |
| `expected` | 기대 결과 (등급, 금리, 지급 여부 등) — 실행 전에 작성한다 |
| `moves_balance` | 실제 GDC 잔액이 움직이는지 여부 (`true` 면 가드 요건 적용) |
| `note` | 이 시나리오를 입력한 이유 (리뷰용) |

## 상품별 매트릭스 (예정)

| 상품 | 축 | 비고 |
|------|----|------|
| 예금 | 금액 x 기간 x 중도해지 | 구현 있음 (`js/gdc-bank.js`) |
| 적금 | 납입 주기 x 만기 x 납입 누락 | 미구현 |
| 대출 | 신용등급 x 금액 x 상환 방식 x 연체 | 구현 있음, 신용평가 연동 |
| 보험 | 상품군(생명/건강/손해/보증) x 사고 유형 x 지급 판단 | 미구현 |
| 증권 | 재무제표 -> 신용등급 -> 기업가치 범위 -> 체결 | 미구현 |
| 디지털 화폐 | 충전 x 이체 x 환율 교환 x 보관 | 구현 있음 |

시나리오 입력 데이터는 가상의 값이다. 실제 개인·기업의 재무 정보를 이 저장소에 올리지 않는다.
