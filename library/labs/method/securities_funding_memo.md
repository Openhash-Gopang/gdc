# 증권 투자와 예치·적금 이자 재원 — 설계 메모 (2026-10-03)

설계 메모이며 명세가 아니다. 코드·서버·시나리오는 아직 없다. 법률 자문용 자료가 아니다.
2026-10-03 대표 결정: 이 프로젝트는 상용 서비스가 아니라 금융기관 종사자 필드테스터가 미래 금융 인프라의 미비점을 찾는 시험이므로, 상용 서비스용 법률 검토를
진행의 선행 조건으로 두지 않는다. 대신 기존 가드(필드테스터 한정, 필드테스트 안내 표기, 법정화폐 환전 LEGAL-HOLD)는 유지한다.
일반 이용자 확대나 법정화폐 환전 개방은 이 결정의 범위 밖이다.

## 1. 구상한 구조 (대표 설명)

예치·적금으로 들어온 GDC를 증권(주식·채권 등)에 투자하고, 그 수익이 예금·적금 이자의 비용(재원)이 된다.
기존 증권사와의 차이는 투자 판단을 **재무제표 기반 평가**(신용평가 v1.0, 기업가치 평가 v0.1)에 두는 것이다.

```
예치·적금(금고) ──운용──▶ 증권 포트폴리오 ──수익──▶ 이자 재원 ──지급──▶ 예치자·적립자
                                  ▲
                    재무제표 → 신용등급 → 기업가치 범위
```

## 2. 이자 지급 방식 — 시뮬레이션에서 비교할 두 가지

| | 수익 연동형 | 확정 이율형 |
|---|---|---|
| 이자 | 기간 운용수익에서 비용을 뺀 만큼을 배분율(설계값)로 나눈다. 수익이 없으면 0 | 약정 이율(적금 명세의 rateBp)대로 지급 |
| 손실 시 | 이자가 줄거나 0. 원금은 금고에 따로 있다고 가정 | 재원이 모자라면 준비금·원금에서 메워야 해서 약정 이행 불가 위험 |
| 시험 대상 | 재원이 있을 때만 지급하는 규칙, 이월 결손 처리 | 약정 이율 상한(현재 0.5%)과 운용수익의 관계 |

적금 명세 v0.1은 확정 이율형 가정으로 쓰여 있다(이율 0~50bp). 수익 연동형으로 바꾸면 이자 계산이 "약정 이율"에서 "기간 배분율"로 바뀌므로 명세의 새 버전이 필요하다. 결정 필요.

## 3. 지금 있는 것과 필요한 것

있는 것: 신용평가 v1.0(등급), 기업가치 평가 v0.1(하한·중간·상한), 적금 시뮬레이터, 한도 명세.
필요한 것(미착수): 증권 종목의 정의(기업이 발행하는 단위가 무엇인가), 가격 결정·체결 규칙, 평가 갱신 주기, 포트폴리오 한도(종목·등급별 집중도),
운용수익 계산과 이자 재원 이전 규칙, 예치금과 운용 자금의 분리(원금이 이자 재원으로 새지 않는 구조).

## 4. "분식 회계가 불가능하다"에 대한 문서 표기 원칙

GDC 거래로 생성되는 장부는 사후 수정이 어렵다는 점은 강점이다. 그러나 "불가능"은 검증할 수 없는 주장이므로 문서·사이트에는 쓰지 않는다.
입력 경로를 구분해 적는다.

| 구분 | 예 | 현재 상태 |
|------|----|-----------|
| GDC 거래에서 자동 생성 | 현금 잔액(`bsCash`) | 있음 (서버 원장) |
| 거래 기록에서 파생 가능하지만 아직 파생하지 않음 | 매출, 매입, 현금흐름 | 없음 — 필드테스터가 입력한다 |
| 장부 밖 사실에 의존 | 매출채권·매입채무의 실재, 순자산 | 수기 입력 |

장부 밖 거래, 특수관계자 간 순환 거래, GDC 밖 자산의 평가는 이 구조가 막지 못한다. 이 한계는 방법론 문서의 "알려진 한계"에 계속 적는다.
필드테스터가 이 지점을 공격해 보는 것(허위 입력으로 높은 등급 받기, 순환 거래로 매출 부풀리기)이 시험 시나리오로 의미가 있다.
